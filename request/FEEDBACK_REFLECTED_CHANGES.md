# 피드백 반영 수정 내역

- pain.html
  - 첫 설명 문장에 반복 원인 파악 표현 보강
  - 추나·통증 페이지의 교통사고 독립 안내 박스 제거
  - 부위별 카드의 교통사고 후유증 항목을 등·흉추 통증으로 교체
  - 약침 FAQ에 약침의 장점과 병행 치료 의미 보강
  - 추나·통증 FAQ의 교통사고 구분 질문을 반복 통증 확인 질문으로 교체
  - 더 자세히 읽어볼 글의 교통사고 항목 교체

- traffic.html
  - 무리한 휴식, 목 보호대 관련 문장 제거
  - Evidence-informed 문단을 환자용 회복 흐름 설명으로 수정
  - 목 보호대 FAQ 삭제
  - Reference 섹션을 더 자세히 읽어볼 글 섹션으로 변경

- about.html
  - 진료철학 문단에서 장비 이름 중심 표현 제거
  - 피부미용 전문성은 책과 강의로 정리해온 경험으로 자연스럽게 반영
  - 피부미용 장비 FAQ 질문을 긍정형으로 수정
  - 장비 수가 아니라는 방어적 표현 삭제
  - 낯설지 않은 표현을 친숙한/일상적으로 와닿는 표현으로 조정

- skin.html
  - 단순한 유행 시술 표현 제거
  - 원리, 성분, 임상 근거를 책과 강의로 정리해온 경험 문장 반영
  - 장비 선택지가 많다는 장점을 살리는 방향으로 문장 수정
  - 시술 종류별 역할 안내 문장 추가
  - 피부미용 FAQ의 방어적 표현 제거
  - 스킨부스터 FAQ에 PN/PDRN, 엑소좀, 히알루론산의 기대 방향을 구체화

- guide.html / faq.html
  - 주차 안내에 건물 주차장 이용 가능 문구 추가
  - FAQ 페이지에서 기본 진료 FAQ와 진료 안내 FAQ를 통합
  - FAQPage 구조화 데이터도 변경된 문항에 맞춰 동기화
