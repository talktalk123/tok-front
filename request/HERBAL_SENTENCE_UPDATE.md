# 한약 문구 최종 반영

- 한약 Core Message 제목을 `보충, 순환, 배출의 방향을 구분합니다`로 수정했습니다.
- 확정 문장 반영:
  한약은 부족한 부분을 채우는 보약이 필요한 경우도 있고, 몸 안의 순환이 막혀 먼저 풀어주어야 하는 경우도 있습니다. 본원은 맥진·설진·복진과 생활 패턴, 증상 변화를 함께 확인해 보충, 순환, 배출 중 어떤 방향이 먼저 필요한지 구분합니다.
- `정리할 부분`, `보강할 부분`처럼 추상적인 표현을 `보약`, `순환`, `노폐물 배출`, `보충·순환·배출 우선순위` 중심 표현으로 정리했습니다.
- herbal.html 및 faq.html의 한약 FAQ 문항과 구조화 데이터 문구를 함께 동기화했습니다.
