# 홈페이지 내용 검토 반영본

## 반영한 주요 수정

1. guide.html의 내부 제작자/SEO 문구를 환자용 위치 안내 문장으로 교체했습니다.
2. index.html의 “환자가 실제로 검색하고” 문장을 환자용 표현으로 수정했습니다.
3. 여러 페이지의 “원장 칼럼을 함께 연결할 수 있습니다” 문장을 실제 공개용 문장으로 수정했습니다.
4. pain.html의 “환자분들이 신기해하는 경우” 문장을 공식 홈페이지에 맞게 순화했습니다.
5. skin.html의 “Equipment Inventory”는 “Aesthetic Devices”로, “보유·도입 장비”는 “진료에 활용하는 장비·성분”으로 수정했습니다.
6. skin.html과 faq.html의 “앞으로도 확장 예정” 문장을 제거하고 현재 활용 중인 진료 기준 중심 문장으로 정리했습니다.
7. about.html과 faq.html의 “본원에서는” 반복 문장을 자연스럽게 정리했습니다.
8. “2026년 K-MEX 서울시 보수교육” 표현은 “2026년 K-MEX 보수교육”으로 안전하게 정리했습니다.
9. guide.html의 비급여 안내 중복 문장을 정리했습니다.
10. footer의 # 링크는 제거하고 네이버 블로그와 전화 예약만 남겼습니다.
11. 각 주요 페이지에 병원명·지역·진료항목·차별점이 자연스럽게 들어가는 엔티티 문장을 보강했습니다.
12. 실제 공개 전 필요한 도메인 치환과 이미지 교체는 그대로 남겨두었습니다.

## 아직 최종 배포 전 확인할 항목

- YOUR-ACTUAL-DOMAIN.example은 실제 도메인 확정 후 canonical, og:url, schema URL에서 일괄 치환해야 합니다.
- 원장 프로필 이미지, 병원 대표 이미지, 병원 위치 안내 이미지는 실제 이미지로 교체해야 합니다.
- 네이버예약, 카카오채널, 인스타그램 URL이 확정되면 footer와 CTA에 다시 연결하면 됩니다.
