# 피부미용 약력·원장 약력 부분 추가 반영

- about.html 약력 영역에 척추도인안교학회 정회원 추가
- about.html 약력 영역에 대한통합레이저의학회 교육위원 추가
- about.html Person schema memberOf에 척추도인안교학회, 대한통합레이저의학회 추가
- skin.html Core Message 아래에 피부미용 진료 기준을 만들어온 활동 섹션 추가
- 기존 문장과 기존 섹션은 삭제하지 않고, 요청받은 약력 관련 내용만 추가

※ 피코레이저 키닥터의 공식 명칭이 별도로 확정되어 있다면 해당 명칭으로 최종 교체 권장.
