# 톡바른경희한의원 본점 홈페이지 HTML 시안 v10 Traffic Independent Navigation

## v10 핵심 수정
사용자 피드백에 따라 교통사고를 `추나·통증` 하위 개념이 아니라, 상단 메뉴의 독립 카테고리로 확실히 분리했습니다.

## 구조 변경
상단 메뉴:
- 메인
- 톡바른 소개
- 한약 진료
- 추나·통증
- 교통사고
- 피부미용
- 진료 안내
- FAQ

## 주요 수정
- 모든 페이지 header nav를 강제로 재구성해 `교통사고` 메뉴가 항상 보이도록 수정
- traffic.html은 `교통사고` 메뉴가 active 상태로 표시되도록 수정
- 메인 페이지의 진료축을 3개에서 4개로 변경
  - 한약 진료
  - 추나·통증 진료
  - 교통사고 진료
  - 피부미용 진료
- 메인에 “교통사고 진료는 독립 카테고리로 자세히 안내합니다” 섹션 보강
- pain.html은 일반 목·허리·어깨·골반 통증과 추나·체외충격파 중심으로 정리
- traffic.html은 자동차보험, 사고접수번호, 사고 후 목·허리 통증, 두통, 몸살, 경과 확인 중심의 독립 랜딩 페이지로 유지
- CSS에서 데스크톱 메뉴가 한 줄에 들어가도록 gap/font-size 조정
- 모바일에서는 기존처럼 가로 스크롤 메뉴 유지

## 남은 실제 공개 전 작업
- https://YOUR-ACTUAL-DOMAIN.example → 실제 도메인
- OG 대표 이미지 URL
- 실제 사진, 지도, SNS/예약 링크
- 실제 주차 안내
- 실제 비급여 고지 항목과 금액

## 자동 점검 결과
모든 공개 HTML에 traffic.html 네비게이션 링크가 포함되어 있습니다.

주요 부정형/내부 메모성 점검어가 발견되지 않았습니다.

## JSON-LD 파싱 결과
모든 공개 HTML의 JSON-LD가 Python json.loads 기준으로 파싱되었습니다.
