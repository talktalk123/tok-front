# AI 게시판 글 작성 샘플

운영자/작업자에게 미리 데이터를 만들어달라고 요청할 때 이 디렉토리를 통째로
공유하면 됩니다.

## 디렉토리 구성

| 파일 | 용도 |
|---|---|
| `_blank-template.txt` | 빈 마스터 템플릿. 새 글 만들 때 복사해서 채워넣으세요. |
| `_ai-prompt.txt` | AI(ChatGPT/Claude)에 줄 프롬프트 베이스. 주제만 바꿔서 사용. |
| `01-clinic-info.txt` | 한의원 안내·정보 — 완성 예시. |
| `02-treatment-detail.txt` | 진료/치료 상세 설명 — 완성 예시. |
| `03-faq.txt` | 자주 묻는 질문 (5문항) — 완성 예시. |
| `04-news.txt` | 소식·공지·운영 안내 — 완성 예시. |
| `05-review.txt` | 시술 후기(1인 사례) — 완성 예시. |
| `06-case.txt` | 익명 임상 사례 — 완성 예시. |
| `07-lecture.txt` | 강의 후기 — 완성 예시. |

## 작업 흐름

1. 작성할 글의 카테고리를 정합니다.
2. 해당 카테고리의 샘플 파일을 열어 톤과 분량을 참고합니다.
3. `_blank-template.txt`를 복사해 새 파일에 붙이고 내용을 채웁니다.
   (또는 `_ai-prompt.txt`를 복사해서 AI에게 시킨 뒤 결과를 받습니다.)
4. 완성된 텍스트를 admin 페이지(`/admin/posts/new`)의 입력창에 그대로
   붙여넣고 "글 등록"을 누릅니다.

## 마스터 템플릿 형식

```
---
title: 글 제목 (필수)
slug: url-friendly-slug          # 비우면 제목에서 자동 생성
summary: 1~2 문장 요약            # 비우면 본문 첫 단락에서 자동 추출
category: clinic-info             # 7개 중 하나
tags: 태그1, 태그2                # 쉼표 구분
publishedAt: 2026-05-10           # YYYY-MM-DD. 비우면 오늘
language: ko-KR
---
<h2>섹션 1 제목</h2>
<p>본문 내용...</p>
```

### 카테고리 (`category` 값)

| 값 | 용도 |
|---|---|
| `clinic-info` | 한의원 안내·운영 정보 |
| `treatment-detail` | 진료/치료 영역 상세 설명 |
| `faq` | 자주 묻는 질문 모음 |
| `news` | 소식·공지·휴진 안내 |
| `review` | 한 환자의 시술 후기(익명) |
| `case` | 학술적 톤의 임상 사례 |
| `lecture` | 강의 진행/참석 후기 |

## 작성 규칙 요약

### 본문 HTML
- **h1 사용 금지** — 글 제목은 자동 h1.
- 섹션 = `<h2>`, 하위 섹션 = `<h3>`.
- 강조 = `<strong>`, 인용/주의 = `<blockquote>`.
- 목록 = `<ul>`/`<ol>`/`<li>`, 단락 = `<p>`.
- 외부 링크 = `<a href="https://...">텍스트</a>`.
- 마크다운(`#`, `**`, `-`) 금지.
- 코드블럭, 이미지, 표 사용 안 함.

### 표현 금지
- 단정·과장: "반드시", "확실히", "완벽한", "100%", "최고의", "가장 효과적".
- 효과 단정형 → 가능형:
  - "○○에 효과가 있습니다" → "○○에 도움이 될 수 있습니다"
  - "치료됩니다" → "치료를 도울 수 있습니다"
- 비교 광고: "다른 한의원과 다르게" 같은 표현.

### 시술 후기 / 임상 사례 추가 규칙
- 환자 식별 정보(이름·생년월일·연락처·직장명) 절대 금지.
- 나이는 "30대" 같은 범위로.
- 면책 `<blockquote>` 반드시 포함:
  *본 글은 한 환자분의 진료 사례 안내이며, 동일한 결과를 보장하지 않습니다.*
- 전후 사진·수치 비교 표현 금지.

## 자동 처리되는 항목 (비워둬도 OK)

| 필드 | 자동 동작 |
|---|---|
| `slug` | 제목에서 자동 생성 |
| `summary` | 본문 첫 단락에서 160자 추출 |
| `publishedAt` | 저장 시점의 오늘 날짜 |
| `updatedAt` | 항상 저장 시점으로 갱신 |
