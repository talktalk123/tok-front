# AI 게시판 마스터 포스트 템플릿

이 파일은 **워커가 글을 작성할 때 따라야 하는 단일 표준**입니다. admin
`/admin/posts/new` 입력창에 이 형식 그대로 붙여넣으면, 저장 시
프론트매터(메타데이터)와 본문(HTML)이 자동으로 분리되어 저장됩니다.

## 형식

```
---
title: 글 제목 (필수)
slug: url-friendly-slug          # 비우면 제목에서 자동 생성
summary: 1~2 문장 요약            # 비우면 본문 첫 단락에서 자동 추출
category: clinic-info             # clinic-info | treatment-detail | faq | news | review | case | lecture
tags: 태그1, 태그2                # 쉼표로 구분
publishedAt: 2026-05-10           # YYYY-MM-DD. 비우면 오늘
language: ko-KR
---
<h2>섹션 1 제목</h2>
<p>본문 내용...</p>

<h2>섹션 2 제목</h2>
<ul>
  <li>항목 1</li>
  <li>항목 2</li>
</ul>
```

## 규칙

### 프론트매터
- 항상 `---`로 시작하고 `---`로 닫습니다.
- 각 줄은 `키: 값` 형식.
- 따옴표 없이 입력해도 됩니다.

### 본문(HTML)
- **h1 사용 금지** — 글 제목은 자동으로 h1으로 처리됩니다.
- 섹션 제목은 `<h2>`, 하위 섹션은 `<h3>`.
- 강조: `<strong>`, 인용/주의: `<blockquote>`.
- 목록: `<ul>` / `<ol>` / `<li>`, 일반 단락: `<p>`.
- 외부 링크: `<a href="https://...">텍스트</a>`.
- 마크다운 문법(`#`, `**`, `-` 등)은 사용하지 않습니다.
- 코드블럭, 이미지, 표는 사용하지 않습니다.

### 표현 금지
- "반드시", "확실히", "완벽한", "100%", "최고의", "가장 효과적" 같은 단정·과장.
- 효과 단정형은 가능형으로: "○○에 효과가 있습니다" → "○○에 도움이 될 수 있습니다".
- 비교 광고: "다른 한의원과 다르게" 같은 표현.

### 시술 후기 / 임상 사례 작성 시 추가 규칙
- 환자 식별 정보(이름·생년월일·연락처·직장명) 절대 금지.
- 나이는 "30대" 같은 범위로.
- 면책 문구 `<blockquote>` 반드시 포함:
  *본 글은 한 환자분의 진료 사례 안내이며, 동일한 결과를 보장하지 않습니다.*
- 전후 사진·수치 비교 표현 금지.

## 자동 처리 항목 (비워두면 자동)

| 필드 | 자동 동작 |
|---|---|
| `slug` | `title`에서 영숫자/한글 추출 후 하이픈 변환 |
| `summary` | 본문 첫 단락에서 160자 추출 |
| `publishedAt` | 저장한 날짜로 채움 |
| `updatedAt` | 항상 저장한 날짜로 갱신 |

## 예시

```
---
title: 추나·통증 진료 상담은 어떻게 진행되나요
slug:
summary:
category: treatment-detail
tags: 추나, 통증, 첫진료
publishedAt:
language: ko-KR
---
<h2>첫 진료 흐름</h2>
<p>증상과 생활 패턴을 먼저 확인합니다.</p>

<h2>진찰 항목</h2>
<ul>
  <li>체형과 자세 확인</li>
  <li>근육 긴장도 확인</li>
  <li>관절 가동성 확인</li>
</ul>

<blockquote>심한 두통, 의식 저하 등 응급 평가가 필요한 증상이 있다면 즉시 의료기관에서 평가받으셔야 합니다.</blockquote>
```
